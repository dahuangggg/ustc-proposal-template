# 中国科学技术大学专业学位研究生开题报告 LaTeX 模板

本项目参照 Word 表格整理，供填写中国科学技术大学专业学位研究生学位申请成果开题报告。填写和提交前请以学院及研究生院的最新要求为准。

## 文件说明

- `content.tex`：填写封面信息、勾选项和报告正文。
- `main.tex`：控制页面、字体和表格排版；使用 XeLaTeX 编译。
- `fonts/STXINGKA.ttf`：华文行楷，供未安装该字体的环境使用。其他字体优先使用编译环境中已安装的字体；若缺少，请参照 `main.tex` 中的配置提供相应字体。

## 在 USTC 在线平台使用

1. 在 GitHub 仓库页面选择 **Code → Download ZIP**，下载项目压缩包。
2. 登录 [USTC 多人协作编辑排版工具](https://latex.ustc.edu.cn/)，在项目列表选择 **创建新项目 → 上传项目**，上传压缩包。
3. 打开项目，在设置中将编译器设为 **XeLaTeX**，主文档选择 `main.tex`。
4. 编辑 `content.tex`，根据文件中的注释填写信息和正文，再点击 **重新编译** 查看 PDF。

正文边框的页底补齐可能需要多次编译。若日志中出现 `Frame heights changed`，请再次编译并检查预览，直到该警告消失。页面内容修改后也请检查分页、图表和脚注。

## 填写说明

- 在 `content.tex` 中修改各命令花括号内的内容；填写时删除原有提示文字。正式提交时可将 `\coversample` 的内容清空，去掉封面的“样表”字样。
- 勾选项填写文件注释中列出的选项名称，多个选项用英文逗号分隔。中文关键词之间使用 `\quad`。
- 第二至七节的正文框可随内容跨页；标题放不下时会移到下一页。封面与简况表为固定布局，部分字段会自动缩小字号；内容过多仍可能放不下，请检查编译警告及 PDF。
- 正文可按 `content.tex` 中的示例插入图片、表格和脚注。图片文件需一并上传；图表在填写位置排版。跨页章节的脚注统一排在该节边框结束页，可能与脚注标记不在同一页。
- 长网址使用 `\url{...}`；在正文命令中填写网址时，按 `content.tex` 的注释处理特殊字符。
- 提交前检查样表字样、提示文字、分页、边框及固定表格中的内容。

## 本地编译

安装包含 XeLaTeX 的 TeX 发行版后，在项目目录运行：

```sh
latexmk -xelatex main.tex
```

也可使用 `xelatex main.tex`，但需要在提示重新编译时重复运行，直到边框高度等信息稳定。编译环境还需要 `main.tex` 中所用的宏包和字体。
