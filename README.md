# 中国科学技术大学专业学位研究生开题报告 LaTeX 模板

本项目为中国科学技术大学专业学位研究生学位申请成果开题报告的 LaTeX 模板，参照 Word 表格整理。填写前请以学院和研究生院的最新要求为准。

## 文件说明

- `content.tex`：填写封面信息、勾选项和报告正文。日常使用主要修改这个文件，写参考文献时还要编辑 `references.bib`。
- `references.bib`：参考文献条目（BibTeX 格式）。
- `main.tex`：页面、字体、表格和分页排版；使用 XeLaTeX 编译此文件，一般无需修改。
- `fonts/`：仓库中只包含封面使用的 `STXINGKA.ttf`（华文行楷），其余字体使用系统或平台已安装的字体。

## 在 USTC 在线平台使用

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，下载项目压缩包。
2. 登录 [USTC 多人协作编辑排版工具](https://latex.ustc.edu.cn/)。
3. 在项目列表选择 **创建新项目 → 上传项目**，选择下载的 ZIP 文件。
4. 打开项目，在左侧 **设置 → 编译器** 中将编译器设为 **XeLaTeX**，主文档选择 `main.tex`。
5. 打开 `content.tex`，根据下文和文件中的说明填写；点击 **重新编译**，在右侧查看或下载 PDF。

更新模板时，如果已经在平台上填写过内容，请先把已填写的 `content.tex` 内容合并到新文件中，再上传覆盖，避免填写内容丢失。新版 `main.tex` 依赖 `references.bib`，从旧版更新时需要把这个文件一并上传，否则编译会报错。

## 填写说明

所有内容都写在 `content.tex` 各命令的花括号里，例如 `\newcommand{\studentname}{张三}`。

### 封面“（样表）”

`\coversample` 默认是 `（样表）`。正式提交时把花括号清空，即 `\newcommand{\coversample}{}`，封面上的“（样表）”会去掉，下方题目和信息栏位置不变。

### 勾选项

在对应命令中填写选项名称即可勾选，名称须与 `content.tex` 注释中列出的**完全一致**（包括全角括号），多个选项用英文逗号分隔，留空则不勾选：

```latex
\newcommand{\studymode}{全日制}
\newcommand{\degreetype}{博士}
\newcommand{\doctorachievement}{软件产品, 其他}
\newcommand{\doctorother}{开源工具链}   % 勾选“其他”时填写具体形式
```

选项名称写错时该项不会被勾选，编译日志中会出现警告并列出可选项。

### 报告正文（二至七节）

- 各节命令中预填了表格原有的提示文本，并标有“提示文本，填写时删除”。**填写时请删除提示文本**，否则它会出现在 PDF 中。
- 段落之间用 `\par` 分隔，每段自动首行缩进两字。
- 小节标题：写成 `\subheading{（一）小节名称}`，顶格加粗，不会单独留在页底。
- 插图（图片文件需一并上传）：

  ```latex
  \begin{figure}\centering\includegraphics[width=0.8\linewidth]{route.png}\caption{技术路线图}\end{figure}
  ```

  图会排在所写的位置（不浮动），按“图 1　标题”自动编号；当前页放不下时整张移到下一页。图片文件名建议只用英文字母、数字和下划线。

- 表格：

  ```latex
  \begin{table}\caption{研究进度安排}\begin{tabular}{|l|l|}\hline 时间 & 内容\\\hline 2026年1月 & 文献调研\\\hline\end{tabular}\end{table}
  ```

  表格和表题作为一个整体排版，当前页放不下时整张移到下一页。

- 网址：写成 `\url{https://...}`，过长时会自动断行。
- 脚注：可直接使用 `\footnote{...}`，脚注内容排在该节边框结束的那一页底部，该页放不下时顺延到下一页。

### 参考文献

把文献条目写入 `references.bib`，在第二节“选题依据”的正文中引用，文献列表会按 GB/T 7714-2015 格式自动排在该节末尾：

```bibtex
@article{zhang2024,
  author  = {张三 and 李四},
  title   = {论文题目},
  journal = {软件学报},
  year    = {2024},
  volume  = {35},
  number  = {3},
  pages   = {100--120},
}
```

| 写法 | 效果 | 用途 |
|---|---|---|
| `\cite{zhang2024}` | 上标 [1] | 一般引用 |
| `\cite{a,b,c}` | 上标 [1-3] | 同时引用多篇，连续编号自动合并 |
| `\parencite{zhang2024}` | 平排 [1] | 作为句子成分，如“见文献 [1]” |

- 编号按正文中首次引用的顺序生成；只有被引用过的条目才会出现在列表中。
- 多位作者用 ` and ` 连接，作者超过三位时自动显示为“等”或“et al.”。

### 关键词

中文主题词之间请用 `\quad` 分隔，例如 `异常检测\quad 智能运维`。直接输入的空格在汉字之间会被忽略。英文关键词按表格要求用 `/` 分隔。

### 签名

电子版提交时，可在 `content.tex` 末尾填写签名图片的文件名和签名日期：

```latex
\newcommand{\studentsignature}{sign_student.png}
\newcommand{\supervisorsignature}{sign_supervisor.png}
\newcommand{\practicesignature}{}          % 留空则保留空白横线
\newcommand{\signdate}{2026 年 11 月 1 日}  % 留空则显示空白的“年 月 日”
```

- 签名图片会自动缩放到 9mm 高，居中放在对应横线上，不改变签名区的行距。
- 建议在白纸上签名后扫描或拍照，**去除背景并裁掉四周空白**，保存为透明背景的 PNG，再与 `content.tex` 一并上传。
- 导师签名图片请由导师本人提供或经导师同意后使用。是否接受签名图片请以学院要求为准；不使用图片时，也可导出 PDF 后打印手签再扫描。

### 特殊字符

以下字符在 LaTeX 中有特殊含义，出现在正文中时需要写成右侧形式：

| 字符 | 写法 | 字符 | 写法 |
|---|---|---|---|
| `%` | `\%` | `&` | `\&` |
| `#` | `\#` | `_` | `\_` |
| `$` | `\$` | `~` | `\textasciitilde` |

`\url{...}` 中的 `%` 和 `#` 同样需要写成 `\%`、`\#`。

## 模板自动处理的排版

以下行为由 `main.tex` 自动完成，了解即可：

- **字体**：优先使用系统或平台已安装的 Times New Roman、宋体、黑体、楷体、华文行楷；没有安装时到 `fonts/` 中查找对应文件（仓库只提供华文行楷，其余需自行放入，见“本地编译”）。勾选框优先使用 DejaVu Sans 的 ☐ / ☑，没有该字体时用绘制的方框代替，两种方式大小一致。
- **封面题目**：一行放得下时居中于第一条横线；放不下时续写到第二条横线；两行仍放不下时自动缩小题目字号（最小 14pt）。
- **固定格子**：简况表的中英文题目、摘要、关键词、选题来源，以及封面信息栏，内容放不下时自动缩小字号（表格最小 7pt，封面信息栏最小 12pt）。
- **正文分页**：各节标题前检查当前页剩余空间，不足时换页，标题不会单独留在页底；正文较长时下一节直接接排，不会留下大片空白。空白模板保持原表“二三 / 四五 / 六七”各占一页的版式。
- **边框**：空白时按原表大小留出填写空间；内容超出时边框随文字跨页，段落可以拆到两页；跨页时各页边框下沿落在同一位置；下一节标题被移到下一页时，上一节边框也延伸到这一位置。页面底部有脚注时，边框会为脚注让出空间。同一页上边框到下一节标题的距离保持一致。
- **签名区**：跟在第七节之后，当前页放不下时整块移到下一页。

## 编译日志中的提示

| 提示 | 含义与处理 |
|---|---|
| `Frame heights changed. Rerun to get cross-references right` | 边框高度在本次编译中有更新，需要再编译一遍。在线平台通常会自动重新编译；若发现边框没有延伸到页底，再点一次 **重新编译** 即可。这不是错误。 |
| `××内容过多，缩小字号后仍放不下格子，请精简` | 该固定格子缩到最小字号仍放不下，请精简对应内容。 |
| `封面“××”内容过长，缩小字号后仍放不下，请精简` | 封面信息栏内容过长，请缩短。 |
| `封面题目在 14pt 下仍超过两行，请缩短题目` | 封面题目过长，请缩短。 |
| `无法识别的勾选项“××”，可选项为：……` | 勾选项名称与可选项不一致，请按提示改正。 |
| `The file 'main.bcf' does not contain any citations` | 正文中还没有引用文献，属于正常提示，可以忽略。 |
| `Style 'gb7714-2015' not found` | 编译环境缺少国标参考文献样式。本地编译的安装方法见“本地编译”；在线平台无法自行安装，请按“反馈问题”提供编译日志。 |
| `File 'xstring.sty' not found` | 缺少国标样式依赖的宏包，处理方法同上。 |

## 使用限制

- 单张比一页还高的图、或比边框还宽的表格不会自动缩放，请通过 `width=0.8\linewidth` 等参数自行控制尺寸。
- 某一节跨多页时，该节的全部脚注会排在这一节结束的那一页底部。
- 图和表不能拆分到两页，比一页还高的表格需要自行拆成两张；图表在当前页放不下而移到下一页时，前一页的边框底部会留出一段空白。

## 本地编译

使用包含 XeLaTeX 的 TeX 发行版，在项目目录运行：

```sh
latexmk -xelatex main.tex
```

`latexmk` 会自动编译并运行 Biber 生成参考文献，直到结果稳定为止。若直接使用 `xelatex main.tex`，请按 `xelatex main`、`biber main`、`xelatex main`、`xelatex main` 的顺序编译（插入图片后可能需要再编译一遍），直到日志中不再出现 `Rerun` 提示。

参考文献需要 Biber 和 `biblatex-gb7714-2015` 样式。TinyTeX 等精简发行版可能未预装，可用 `tlmgr` 补装：

```sh
tlmgr install biber biblatex biblatex-gb7714-2015 xstring
```

如果安装后仍提示找不到样式，请运行 `mktexlsr` 更新 TeX 文件索引。

仓库的 `fonts/` 只提供华文行楷。本地缺少 Times New Roman、宋体、黑体或楷体时，需要先安装这些字体，或把对应文件放入 `fonts/`，否则编译会失败。文件名须与 `main.tex` 一致：`times.ttf`、`timesbd.ttf`、`timesi.ttf`、`timesbi.ttf`、`Simsun.ttc`、`SimHei.ttf`、`Kaiti.ttf`。如需在本地显示 DejaVu Sans 的勾选框，可自行安装 DejaVu Sans 字体。
