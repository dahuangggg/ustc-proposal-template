# 中国科学技术大学专业学位研究生开题报告 LaTeX 模板

本项目为中国科学技术大学专业学位研究生学位申请成果开题报告的 LaTeX 模板，参照 Word 表格整理。填写前请以学院和研究生院的最新要求为准。

## 文件说明

- `content.tex`：填写封面信息、勾选项和报告正文。
- `main.tex`：页面、字体和表格排版；使用 XeLaTeX 编译此文件。
- `fonts/STXINGKA.ttf`：华文行楷，供未安装该字体的环境使用。

## 在 USTC 在线平台使用

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，下载项目压缩包。
2. 登录 [USTC 多人协作编辑排版工具](https://latex.ustc.edu.cn/)。
3. 在项目列表选择 **创建新项目 → 上传项目**，选择下载的 ZIP 文件。
4. 打开项目，在左侧 **设置 → 编译器** 中将编译器设为 **XeLaTeX**，主文档选择 `main.tex`。
5. 打开 `content.tex`，根据文件中的说明填写信息及正文；点击 **重新编译**，在右侧查看或下载 PDF。

正文区域会随内容增加而分页；封面及简况表使用固定布局，填写较长内容后请检查是否超出边框。文件中的提示文字如果没有被填写内容替换，会出现在 PDF 中，提交前请检查并清理。

## 本地编译

使用包含 XeLaTeX 的 TeX 发行版，在项目目录运行：

```sh
latexmk -xelatex main.tex
```

也可用 `xelatex main.tex` 编译。模板优先使用系统字体；缺少所需字体时，需要根据 `main.tex` 的字体配置提供相应文件。在线平台已经测试过 XeLaTeX 编译。
